# BookRecommender

## Описание проекта

**BookRecommender** — это ML-сервис рекомендации книг с веб-интерфейсом. Пользователь регистрируется, входит в систему, описывает книгу, которая ему понравилась, и получает список похожих по смыслу книг с процентом сходства. Все запросы сохраняются в базе данных, и пользователь может просматривать историю своих запросов.

Проект построен на трёхкомпонентной архитектуре и упакован в Docker-контейнеры:

- **Flask Web App** (порт 5000) — пользовательский интерфейс: регистрация, авторизация, форма ввода описания, отображение рекомендаций, история запросов.
- **FastAPI ML API** (порт 8000) — сервис машинного обучения, который на основе смыслового поиска (semantic search) находит книги, похожие на описание пользователя.
- **SQLite** (файл) — хранит пользователей и историю запросов (может быть легко заменён на PostgreSQL).

## Зачем нужен этот проект

Книжные магазины, библиотеки и читательские сервисы часто сталкиваются с проблемой: пользователь не может найти книгу, потому что не помнит точное название или автора, но может описать её словами («история про мальчика-волшебника», «роман о любви и ревности»).

**BookRecommender** решает эту задачу через семантический поиск: нейросеть преобразует описание пользователя и описания книг в векторы (числовые представления смысла) и находит книги с наиболее похожим смыслом. Это позволяет:

- Находить книги по смыслу, а не по ключевым словам.
- Упрощать и ускорять поиск для читателей.
- Использовать в библиотеках, книжных магазинах и рекомендательных сервисах.

Docker, docker compose

Инструменты: ruff (линтер/форматтер), mypy (strict), pytest, pre-commit, commitizen (Conventional Commits

Как работает приложение
Регистрация
Пользователь заходит на /register, вводит логин и пароль. Пароль хешируется (bcrypt) и сохраняется в таблице users. После регистрации — редирект на страницу входа.

Вход
Пользователь вводит логин и пароль на /login. Если данные верны — создаётся серверная сессия, и пользователь попадает на главную страницу. Неавторизованных пользователей перенаправляет на страницу входа.

Поиск похожих книг
На главной странице (/) пользователь вводит описание книги (например, «Мне очень понравилась книга про мальчика, который узнаёт, что он волшебник»). Flask отправляет этот текст в FastAPI (POST /recommend). FastAPI векторизует текст с помощью sentence-transformers и вычисляет косинусную близость с эмбеддингами всех книг из базы. Результат — 5 самых похожих книг с процентом сходства — возвращается во Flask и отображается пользователю. Каждый запрос автоматически сохраняется в таблице recommendations.

История запросов
На странице /history отображается таблица всех запросов текущего пользователя: номер, описание, рекомендованная книга, автор и дата запроса.

Swagger ML API
FastAPI автоматически генерирует интерактивную документацию, доступную по адресу http://localhost:8000/docs. Здесь можно протестировать эндпоинты /recommend, /health, /model-info и авторизацию вручную.
